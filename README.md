# 奶龙管理系统 Demo - Vite 前端模板

基于 Vue 3 + Vite 构建的奶龙管理系统前端 Demo，集成 Element Plus 组件库、Vue Router 路由管理和 Axios 网络请求，专注于奶龙及奶龙类型的管理功能，提供快速搭建单页应用的基础框架。

## 核心功能

- **奶龙管理**：支持奶龙信息的增删改查，可按类型、状态筛选，包含编号、名称、颜色等信息管理
- **奶龙类型管理**：维护奶龙类型数据，记录类型特征、饲养要求、栖息地等详细属性
- **基础框架**：基于 Vue 3 `<script setup>` 语法简化开发，配合 Element Plus 提供直观 UI 交互

## 技术栈

- **核心框架**：Vue 3.5.13
- **构建工具**：Vite 5.1.4（快速热更新与构建）
- **UI 组件**：Element Plus 2.9.9
- **路由管理**：Vue Router 4.2.5
- **网络请求**：Axios 1.6.7（封装请求/响应拦截器）

## 快速开始

### 环境要求

- Node.js v18.0.0+
- npm v8.0.0+

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发环境（默认地址：http://localhost:5173）
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 项目结构


## 接口说明

系统封装了奶龙管理相关核心接口，包括：

- 奶龙信息：获取列表、新增、编辑、删除、按类型 / 状态查询
- 奶龙类型：获取类型列表、维护类型详情（特征、饲养要求等）

详细接口文档可参考项目内 jiekou.md 文件。

## 开发指南

- **组件开发**：推荐使用 Vue 3 `<script setup>` 语法，简化组件代码
- **路由配置**：在 `src/router` 目录定义页面路由，支持单页应用跳转
- **网络请求**：通过封装的 Axios 实例发送请求，包含错误处理与状态提示

## 部署说明

1. 执行 `npm run build` 生成生产文件（输出至 `dist` 目录）
2. 将 `dist` 目录文件部署至 Web 服务器
3. 配置服务器路由指向 index.html 以支持单页应用路由

## 常见问题

- 开发服务器启动失败：检查端口占用或依赖安装问题
- 接口请求错误：确认后端服务是否启动，可在 src/api/dragon.js 调整基础路径
- 依赖安装问题：尝试清除 npm 缓存或切换镜像源
